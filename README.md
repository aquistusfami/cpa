# 🎓 HUST CPA Calculator

A simple, fast, and modern CPA (Cumulative Grade Point Average) calculator for students at Hanoi University of Science and Technology (HUST).

## ✨ Features

* **Auto-suggestion:** Includes a built-in database of 8,252 HUST courses. Just type the course code (e.g., `IT1110`) and it auto-fills the name and credits.
* **Instant Calculation:** Calculates your CPA (4.0 scale) and total credits in real-time.
* **Auto Save:** Your grades are saved automatically in your browser (Local Storage). You won't lose them when you refresh the page.
* **Import & Export:** Easily save your data as a `.json` file or load it on another device.
* **Modern UI:** Clean, responsive dark-mode design.

## 🛠️ Built With

This is a 100% static website. No backend or database server is required!
* HTML5
* CSS3
* Vanilla JavaScript

## 🚀 How to Run Locally

Because this project uses the `fetch()` API to read the `courses.json` file, opening the `index.html` directly in your browser might not work due to CORS security policies. 

To test it on your computer:
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html` and select **"Open with Live Server"**.
